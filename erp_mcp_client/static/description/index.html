Step-by-step setup

Six processes, about five minutes

Follow them in order. Every step has the exact screenshot from the real interface.

PROCESS 1 · ~1 MIN Install the free module In Odoo
PROCESS 2 · ~2 MIN Create Google OAuth credentials Google Cloud Console
PROCESS 3 · ~1 MIN PER ROLE Generate an Odoo API key In Odoo
PROCESS 4 · ~1 MIN Configure & register the connector In Odoo
PROCESS 5 · ~1 MIN Authorize the URLs in Google Odoo + Google Console
PROCESS 6 · ~1 MIN Connect your AI client & sign in In your AI client
PROCESS 1 In Odoo ~1 min

Install the free module

Add MCP Connector to the Odoo database you want to expose, then open it to create your first connection.

1
Install & activate

Go to Apps, find MCP Connector and install it.

2
Create a new connection

Open MCP Connector → Connectors and click New.

PROCESS 2 Google Cloud Console ~2 min

Create Google OAuth credentials

The connector signs your users in with Google. Create an OAuth client at console.cloud.google.com and copy its Client ID & Secret. Redirect URLs come later, in Process 5.

1
Open APIs & Services

In Google Cloud console, open APIs & Services from Quick access.

2
Go to Credentials

In the left menu, select Credentials.

3
Create credentials

Click + Create credentials at the top.

4
Choose OAuth client ID

Select OAuth client ID from the dropdown.

5
Application type

Set Application type to Web application.

6
Name it & create

Any name works (e.g. “Odoo MCP Connector”). Leave URIs empty for now and click Create.

7
Copy Client ID & Secret

Paste both into the matching fields of the module. The secret is shown only once — store it safely.

PROCESS 3 In Odoo ~1 min per role

Generate an Odoo API key

Each role connects with its own API key, generated by the Odoo user that role represents. Repeat for every role — admin, sales, read-only…

1
Open My Preferences

Click your avatar (top-right) → My Preferences.

2
Security → Add API Key

Open the Security tab and click Add API Key.

3
Confirm your password

The user creating the key confirms with their Odoo password.

4
Name it & set validity

Give it a clear name. A Persistent Key is recommended so the connection never expires.

5
Generate the key

Click Generate key.

6
Copy it into the module

Paste it into the Odoo API Key field of the matching role. It is shown only once.

PROCESS 4 In Odoo ~1 min

Configure & register the connector

Fill in the registration form with everything you gathered, add your roles, and register.

1
Name, Google keys & instance

Paste the Google Client ID / Secret and set the Odoo URL and Database — the “Use this instance” / “Use current DB” shortcuts fill them in.

2
Add roles: API key + email

In Access Roles, add one line per role: name, Odoo API key and the email(s) allowed to use it.

3
Click Register

Press Register. Status changes to Registered and your MCP instance is provisioned.

PROCESS 5 Odoo + Google Console ~1 min

Authorize the URLs in Google

Registration generates three URLs. Two of them go into your Google OAuth client so sign-in is trusted.

1
Copy the generated URLs

Registration Result shows the Google Origin URL, Google Callback URL and AI Connector URL. Use the copy buttons.

2
Paste them into Google

Origin URL → Authorized JavaScript origins. Callback URL → Authorized redirect URIs. Save.

3
Re-register

Back in Odoo, click Re-register. Copy the AI Connector URL — that is the link you share with your team.

PROCESS 6 In your AI client ~1 min

Connect your AI client & sign in

Shown in Claude — the flow is the same in ChatGPT or any MCP-compatible client.

1
Add a custom connector

Open Settings → Connectors, then Add → Add custom connector.

2
Name & connector URL

Any name; paste the AI Connector URL into the URL field.

3
Connect

Click Connect to start sign-in.

4
Allow access

Sign in with Google and click Allow Access. Only listed emails get through — each within its role’s permissions.

Done

FAQ

Frequently asked questions

Do I have to give people my Odoo password?

No. You share one connector link. Users sign in with Google; access is decided by their email and its role.

Does it work with ChatGPT too?

Yes. Any AI client that supports custom MCP connectors works — the connector URL is the same.

Can I limit someone to read-only?

Yes. Point a role at an Odoo user with read-only rights and add their email.

Are custom modules supported?

Yes. The connector reads models and fields directly from your Odoo, so custom ones work out of the box.

Where does my data live?

In your Odoo. The connector proxies authorized API calls and keeps no copy of your database.

Someone joined or left — what do I do?

Edit the role’s email list and press Re-register. Access updates instantly.
